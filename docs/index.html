Build. Break. Learn. Repeat.

Local Kubernetes labs with full node access.

klabctl creates production-like multi-node clusters on Multipass with kubeadm. Separate control-plane and worker VMs, Calico, and a kubeconfig on your machine. No managed cluster cost.

Install klabctl View on GitHub

A lab, not a toy cluster

Use kind or Minikube when you only need to run an app. Use klabctl when you want the node, the join flow, and the control plane.

One command

klabctl create launches the VMs, installs containerd and kubeadm, initializes the control plane, joins the nodes, and installs Calico.

Real nodes

Control-plane and worker counts are yours. A 3 control-plane, 2 worker lab is a create flag, not a diagram.

Shell on every VM

Inspect kubelet, certificates, containerd, and systemd. Restart a node. Practice the failures managed clusters hide.

Install

The package only depends on bash. One .deb installs on Ubuntu 24.04 or newer, Debian, Linux Mint, Pop!_OS, and other dpkg systems. On any other Linux that can run Multipass, clone the repo.

# Ubuntu 24.04+, Debian, Mint, Pop!_OS
curl -fsSL -o /tmp/klabctl.deb \
  https://ppa.launchpadcontent.net/skalekontrol/klabctl/ubuntu/pool/main/k/klabctl/klabctl_0.1.0_all.deb
sudo apt install -y /tmp/klabctl.deb
klabctl version

# Any other Linux with Multipass
git clone https://github.com/SkaleKontrol/klabctl.git
cd klabctl
chmod +x klabctl.sh
./klabctl.sh version

Create a cluster

Multipass and host kubectl need to be installed first. The default cluster is one control plane and one worker, Kubernetes 1.36.

# Default lab
klabctl create k8s

# High-availability lab. Sizes are per node.
klabctl create lab \
  --control-planes 3 --workers 2 \
  --cp-cpus 2 --cp-memory 4G --cp-disk 20G \
  --worker-cpus 2 --worker-memory 4G --worker-disk 20G

kubectl get nodes

Kubernetes versions

The same release is installed on every node. Pick a minor for its newest patch, or pin a patch.

SettingValue
Default1.36, newest patch
Targeted minors1.35, 1.36, 1.37
 
klabctl create lab --k8s-version 1.35
klabctl create lab --k8s-version 1.36.5
